# Música de Braulio Garcia

Os arquivos de áudio que tocam em [brauliogarcia.com.br/musica](https://brauliogarcia.com.br/musica/): faixas em nome próprio e o disco *Ternura Inox*, da Nave Vaga. `catalogo.json` lista cada faixa com título, ano, duração, página no site e endereço do MP3; `index.html` é o player em janela própria. Gerado por `montar_musica.py` (pasta de implementação do site pessoal).

Todos os direitos das gravações pertencem ao autor.
